# TMDB（試作6の結果）

2026-10-23 に、TMDB の API で、映画チェッカーの作品と、ドラマ・アニメの情報が取れるかを試した結果と、使い方の決まりをまとめる。

## 前提

- 鍵は記録の保管場所（非公開）の `records/keys.json` の `tmdb`。ホームの「外部サービスの鍵」から本人が入れる。会話やこのリポジトリには書かない。
- Claude の作業場所と定期タスクから `api.themoviedb.org` に接続できるよう、claude.ai の設定で許可してある。
- TMDB の規約に従い、映画の画面に TMDB のクレジット（「This product uses the TMDB API but is not endorsed or certified by TMDB.」とロゴ）を出す。配信先の情報は JustWatch 由来なので、配信先を出すところに「配信情報：JustWatch」と添える。

## 映画（映画チェッカーの50作品で試した）

- 作品の特定：50/50 で正しい作品に当たった（上位20作品と、残りから無作為に30作品）。
- 決まり：
  1. 邦題で `/search/movie`（`language=ja-JP`）を引き、公開年が ±1 年の候補に絞る。なければ英題で引き直す。
  2. 候補が複数あるときは、評価数（`vote_count`）がいちばん多いものにする。最初の候補を取ると「公開直前スペシャル」「メイキング」などに当たることがあった（3/50）。
  3. 作品ごとに TMDB の作品番号を覚えておき、2回目からは検索せずに作品番号で引く。
  4. 上映時間が手元の値と15分以上違うときは、別の作品に当たったおそれがあるので確認待ちにする。
- 上映時間：50/50 で取れた。手元の値と ±3 分で一致したのは 46/50。違ったものは版の違い（4〜9分）。
- 国内の配信先（`watch/providers` の `JP`）：何らかの配信があるのは 40/50、見放題があるのは 35/50。手元の配信情報（2026年9〜10月にClaudeが調べたもの）と、見放題の有無が食い違う作品が数本あった。どちらが新しいかは時期によるので、TMDB の取得日を一緒に記録する。
- 呼び出しの数：1作品につき2回（検索と詳細。詳細に配信先を含める）。50作品で約13秒。映画チェッカーの全2,074作品に作品番号を付けるのは1回だけで、約4,000回・10分ほど。週1回の更新は、作品番号で詳細だけを引くので1作品1回。

## ドラマ・アニメ（7作品で試した）

- `/search/tv` → `/tv/{作品番号}` で、シーズンごとの話数と放送開始の月、全体の状態（放送中・終了）、国内の配信先が取れる。
- 1話の長さ（`episode_run_time`）は空のことが多い。要るときはシーズンの詳細から引く。
- アニメの「期」と TMDB のシーズンの区切りが一致しないことがある（TMDB では1シーズンにまとめられている作品がある）。画面ではシーズンと話数を TMDB の区切りで出し、本人がメモで補えるようにする。
- 新しいシーズンの知らせ：シーズンの一覧に新しいシーズンが加わったとき、または `next_episode_to_air` が入ったときに知らせる。

## 配信サービスの名前の読み替え

| TMDB の名前 | アプリでの扱い |
| --- | --- |
| Amazon Prime Video、Amazon Prime Video with Ads | プライムビデオ（見放題）。契約中 |
| Amazon Video | プライムビデオのレンタル・購入 |
| U-NEXT、HBO Max on U-Next | U-NEXT（見放題）。契約中 |
| Netflix、Netflix Standard with Ads | Netflix（見放題）。必要なときだけ加入 |
| 「… Amazon Channel」 | プライムビデオの追加チャンネル（別料金）。見放題には数えない |
| そのほか（Hulu、Disney Plus、FOD など） | 名前をそのまま出す |
