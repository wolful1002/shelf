# 記録の保存の形（設計メモ）

最初の版で使う、`wolful1002/shelf-data`（非公開）への記録の置き方。要件定義は claude.ai のプロジェクトの `claude/requirements.md`。

## 1. フォルダ構成

| 場所 | 中身 | 書く人 |
| --- | --- | --- |
| `works/novels.json` | 必読書チェッカーの作品とリスト（2,767冊・38本） | Claude（リストの追加・書誌の確認） |
| `works/novels-biblio.json` | 毎朝の書誌確認による修正と、確認済みの作品 | Claude |
| `works/films.json` | 映画チェッカーの作品とリスト（2,074本・18本） | Claude |
| `records/library/0.json` 〜 `f.json` | 蔵書。1冊、または1シリーズが1件。記録の番号で16のファイルに分ける | アプリ・Claude |
| `records/reading.json` | 本の読了・読書中・読みたい（チェッカーの作品と蔵書の本の両方） | アプリ・Claude |
| `records/films.json` | 映画の鑑賞（回ごと）・観たい。リスト外の作品の鑑賞もここ | アプリ・Claude |
| `records/booklog.json` | ブクログの記録と、照合の状態 | アプリ・Claude |
| `records/queue.json` | 確認待ち | アプリ・Claude |
| `records/settings.json` | 保管場所の一覧と場所ラベルの番号、表示の設定 | アプリ |
| `tasks/` | Claudeの定期タスクの作業状態（書誌確認の待ち行列など） | Claude |
| `import/` | 移行前の写し。書き換えない | — |

`works/` はアプリからは読むだけ。記録（`records/`）と作品（`works/`）を分け、作品データの更新が記録を巻き込まないようにする。

## 2. 書き込みの仕組み

- **変更は小さな「操作」で送る。** 例：「記録 b8k2… の保管場所を『書斎A-1』にする」。アプリはファイルを読み、操作を当て、書き戻す。書き戻すときに別の端末が先に書いていたら（GitHubが409を返す）、読み直して同じ操作を当て直す。こうすると、2台で別々の本を同時に変えても、どちらの変更も残る。
- **同じ記録を2台で同時に変えた場合**は、後から届いた変更が勝つ。記録ごとに更新時刻 `u` を持つ。
- **送信待ち**：電波のないときの操作は端末に貯め、電波が戻ったら順に送る（試作で確認済み）。
- **ファイルの大きさ**：1つのファイルを1MB未満に保つ。蔵書を16に分けるのはこのため（3,000冊でも1ファイル約60KB）。

## 3. 端末での読み込み

- 端末にすべての記録と作品の写しを持つ（ブラウザの保存領域）。電波がなくても一覧と所持確認が動く。
- 開いたときは、保管場所の全ファイルの一覧と指紋（GitHubの `git/trees`）を1回だけ取り、前回から変わったファイルだけを取り直す。

## 4. 記録の形

### 蔵書（`records/library/*.json`）

ファイルの中身は `{ "items": { 記録の番号: 記録 } }`。

| 項目 | 意味 | 例 |
| --- | --- | --- |
| `id` | 記録の番号（端末で作る） | `b-mo2x8k-4f1a` |
| `kind` | 種類の大枠 | `book`（1冊）／`series`（シリーズ） |
| `cat` | 本の種類（12種） | `小説`・`漫画`・`詩歌` など |
| `t`, `a` | 書名、著者 | |
| `isbn`, `mag` | ISBN、雑誌コード | |
| `pub`, `label`, `tr`, `y` | 出版社、レーベル、訳者、刊行年 | |
| `fmt`, `ccode` | 判型、Cコード | `文庫`、`C0197` |
| `media` | 紙か電子か | `paper`／`ebook` |
| `loc` | 保管場所（電子はストア名） | `書斎・本棚A・1段目` |
| `note` | 版のメモ | |
| `st` | 状態 | `own`（所有）／`off`（所有を外した）／`gone`（手放した） |
| `src` | 登録の入口 | `scanner`・`camera`・`search`・`manual`・`checker`・`booklog`・`purchase` |
| `nk` | 必読書チェッカーの作品の番号（結び付いていれば） | `52abdb42` |
| `link` | 照合の状態 | `auto`（自動）・`manual`（手で選んだ）・`none`（結び付けない）・`wait`（確認待ち） |
| `series`, `vol` | 小説のシリーズの各巻のとき、シリーズの記録の番号と巻 | |
| `vols` | シリーズの記録のとき、巻ごとの所持・ISBN | `{"1":{"own":1,"isbn":"978…"}}` |
| `total`, `done` | シリーズの既刊数、完結 | |
| `added`, `u` | 登録日時、更新日時 | |

### 本の読書の状況（`records/reading.json`）

`{ "items": { 対象: 状況 } }`。対象は、チェッカーの作品なら `n:作品番号`、蔵書の本なら `b:記録の番号`、シリーズの巻なら `b:記録の番号#巻`。

| 項目 | 意味 |
| --- | --- |
| `s` | `read`（読了）／`reading`（読書中）／`want`（読みたい） |
| `d` | 読了日（分からなければなし） |
| `via` | 誰が付けたか：`manual`（手で）・`post`（SNSの投稿から）・`booklog`・`checker`（移行） |
| `n` | 読んだ回数（再読で増える） |
| `u` | 更新日時 |

チェッカーの作品と蔵書の本が結び付いている場合、読書の状況はチェッカー側の `n:` に1つだけ持つ（二重に持たない）。

### 映画（`records/films.json`）

`{ "items": { 対象: 記録 } }`。対象は、映画チェッカーの作品なら `f:作品番号`、リスト外の作品なら `x:記録の番号`。

| 項目 | 意味 |
| --- | --- |
| `views` | 鑑賞の回ごとの記録 `[{ "d": 日付, "at": 場所 }]`。日付や場所が分からなければ省く |
| `want` | 観たい印 |
| `t`, `y` | リスト外の作品のときだけ、題名と公開年 |
| `u` | 更新日時 |

### 確認待ち（`records/queue.json`）

`{ "items": { 番号: { "type": 種類, "target": 対象, "cands": 候補, "why": 根拠, "at": 作成日時 } } }`。決めたら消す。決めた結果は該当する記録に書く。
