# 購入確認・予約確認メールからの取り込み（試作5の結果）

2026-10-23 に、取り込み専用のGmailアカウントに転送した22通で、読み取りを試した結果と、取り込みの決まりをまとめる。
（このリポジトリは公開なので、名前・注文番号・お届け先などの個人の情報はここに書かない）

## 前提

- Claudeが読むのは取り込み専用のアカウントだけ。今のアカウントからは、振り分けで決まった差出人のメールだけが自動で転送される。
- Gmailのコネクタは「探す・読む」（search_threads・get_thread・get_message）だけを許可している。
- 記録に残すのは、書名・購入日・お店・紙か電子か（映画は作品名・館名・上映日時・座席・上映形式）だけ。名前・住所・支払い方法・注文番号・暗証番号・予約番号は残さない。
- 手で転送したメールは本文の先頭に「---------- Forwarded message ---------」と元の From・Date・Subject が付く。自動転送のメールは差出人がお店のまま。どちらも読めるようにする。購入日は元のメールの日付（手で転送したものは本文中の Date）を使う。

## お店ごとの読み方

### Amazon（紙）auto-confirm@amazon.co.jp「注文済み: 「…」」

- 商品は「注文内容の表示と変更」から「合計」までの間。1商品ごとに `[image: 書名の全文]` と商品ページへのリンク（`/dp/商品番号`）と「数量」がある。表示の書名は途中で「...」と切れるので、`[image: …]` の全文を使う。
- 「合計」より後（「あなたにイチオシ」「もう一度買う」「お客様が閲覧した商品に関連する商品」など）はおすすめなので読まない。
- 本かどうかは商品番号で決める。**数字10桁（末尾がXのこともある）なら本のISBN（10桁）**なので、13桁に直して書誌サービスで引く。
- 商品番号が「B0…」のもの：書名に「[雑誌]」「…号」があれば雑誌として確認待ち。「[DVD]」「[Blu-ray]」なら映画のソフト（第2版の映画ソフトの所有で使う）。ほかは本・漫画ではないので取り込まない。
- お届け先は「*名前 - 都道府県*」の行。自分の名前と違えば贈り物なので確認待ち（要件4章）。自分の名前は記録の保管場所（非公開）の設定に置いて比べる。

### Kindle（電子）digital-no-reply@amazon.co.jp「Amazon.co.jpでのご注文: …」「…と、他N点のアイテムからなる…」

- 「注文日:」の行が購入日。商品は「注文の詳細」から「注文の詳細を表示する」までの間。1商品ごとに `/dp/B0…` のリンク、書名、「販売者: 出版社」がある。
- 「自分のほしい物リストに登録されている商品」より後はおすすめなので読まない。
- ISBNはないので、書名で書誌サービスを引く。書名の括弧（「ヤングジャンプコミックスDIGITAL」「ガガガ文庫」など）と「[雑誌]」で種類の手がかりにする。
- まとめ買い（例：同じ漫画の1〜11巻）は、巻数で1つのシリーズにまとめる（蔵書の登録と同じ流れ）。

### 楽天ブックス books-notification@mail.books.rakuten.co.jp「【楽天ブックス】発送のご案内」

- 「注文日時：」が購入日。商品は「■商品の詳細」の「・商品名：…」と「- 数量：…」。ISBN・著者はないので書名で引き、迷うものは確認待ち。
- 発送のご案内で注文が確定する（メール本文にそう書かれている）ので、これを登録のきっかけにする。注文確認（books-order@…）は、発送の前の予約の把握に使う。
- 「・お届け先お名前：」が自分と違えば確認待ち。

### イオンシネマ e-reserve@aeonent.jp「e席リザーブ完了通知」

- 「■ 劇場名：」（例：旭川駅前 → イオンシネマ旭川駅前）、「■ 作品名：」、「■ 上映開始時間：」、「■ 座席：」を読む。
- 作品名の先頭の「字幕」「吹替」は上映形式として分けて、作品名からは外す（例：「字幕 Mr.ノボカイン」→ 作品「Mr.ノボカイン」・字幕）。
- 予約として記録し、上映日時を過ぎたら確認待ちに「この回を観ましたか」を出す（要件7章）。

### ローソン・ユナイテッドシネマ thanks@unitedcinemas.jp「チケット購入のお知らせ（ローソン・ユナイテッドシネマ グループ）」

- 「●作品・劇場・時間」の「劇場：」「作品名：」「鑑賞日：」「上映時間：開始～終了」「スクリーン：」と、「●座席」の次の行を読む。
- 「劇場：」は短い名前（例：旭川）なので、末尾の劇場の署名（例：シネプレックス旭川）を館名に使う。
- 作品名の末尾の「（字幕）」「（吹替）」は上映形式として分ける（例：「オデュッセイア（字幕）」→ 作品「オデュッセイア」・字幕）。
- 上映時間の開始と終了から、だいたいの上映時間（予告込み）が分かる。
- 同じメールを2回転送したものがあった。元の送信日時・作品名・上映開始が同じものは1件にまとめる。
- 購入番号・電話番号・会員番号・ポイントは記録に残さない。

### イオンシネマ ac.tickets-info@aeonent.jp「購入番号：…」

- ACチケット（鑑賞券の前売り）の購入で、作品・日時がない。取り込まない。暗証番号が書かれているので、振り分けの対象から外した（2026-10-23）。

## まだ確かめていないこと

- 予約・注文の取り消しのメールの形（これまで取り消したことがなく、見本がない。届いたら確かめる。それまでは、上映日時を過ぎた予約を「観ましたか」の確認待ちに出すことで、観なかった回を外せる）。
- honto とル・シネマの差出人。
- 書名だけ（Kindle・楽天）で書誌サービスを引いたときに、正しい本に当たる割合（第2版の前に、取り込み済みの書名で測る）。
