この端末の鍵（記録の保管場所）

記録を読み書きするための GitHub の鍵は、この端末にだけ置いています。人に貸す・手放す端末では消してください。消すと、端末に置いた記録の写しも消え、この端末からは記録を読めなくなります（送っていない変更があれば、先に送ってから消します）。

端末を失くしたとき
  1. 別の端末かパソコンで GitHub にサインインし、右上の自分のアイコン → Settings → 左の一番下の Developer settings → Personal access tokens → Fine-grained tokens を開きます。
  2. このアプリに入れた鍵（shelf-data に使える鍵）の Delete を押して消します。これで、失くした端末の鍵は使えなくなります。
  3. 同じ画面の Generate new token で鍵を作り直します。「Repository access」は Only select repositories で shelf-data だけ、「Permissions」は Contents を Read and write だけにし、期限を付けます。
  4. 使う端末で、この画面の「鍵を入れ直す」から新しい鍵を入れます。
  5. 念のため、GitHub の shelf-data の履歴（Commits）に、心当たりのない「アプリから更新」が無いか見ます。あれば、その前の版に戻せます（Claude に頼めます）。
